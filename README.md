# Album library

My hand-curated album library, as one `library.json` file. It's the content
shown by [spotify-album-viewer](https://github.com/juliandescottes/spotify-album-viewer),
which loads it from this repo.

Edit it with the app: clone both repos side by side, run `npm run dev` in the
app, and its Save button writes `library.json` here. Then commit and push this
repo. The file format is described in the app's `docs/spec.md`.
